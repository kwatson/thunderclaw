Set up ThunderClaw

One extension.
A connection you choose.

Configure your provider and model directly in Thunderbird. Your connection and API key stay saved on this device across restarts.

The standalone edition is currently a development build. Follow the installation guide for the current version.

  1. 01

    Add the extension

    Use Thunderbird 128 or newer. Install the XPI through Add-ons and Themes → Install Add-on From File, then open ThunderClaw settings.

    Installation guide ↗
  2. 02

    Choose your connection

    Select a provider preset or enter a compatible API base. For Ollama or LM Studio, start your local server and load a suitable model.

  3. 03

    Pick a model and save

    Enter an API key if required. Click Load models and choose one, or enter its exact ID. Save the connection and approve host access when Thunderbird asks.

  4. 04

    Test, then try it

    Click Test connection to check your model with synthetic text. Then select text in a draft, generate a preview, and decide whether to apply it.

Use HTTPS for remote servers. Local HTTP supports explicit 127.0.0.1 or [::1] addresses.

Generate, Preview, Apply, and Undo are separate choices. Thunderbird handles sending. Models have no authority to change recipients, attachments, or headers.

Keep supported formatting

Eligible selections on qualified Thunderbird 153+ versions support paragraphs, flat lists, bold, italic, and underline. Received translations keep the message’s existing structure.

Know where your text goes

Actions send selected content and necessary context directly to your chosen endpoint. Provider privacy policies apply. Local servers and routing services can use upstream cloud models.

A few useful details

Before you get started.

Will I have to enter my API key every day?

Your key is saved in your local Thunderbird profile and survives restarts. It is never synchronized. Local profile storage is not an encrypted vault, so protect your device and backups. Remove the saved key in settings; revoke it with your provider if needed.

Can I use a model running on my computer?

Yes. Ollama and LM Studio have presets, and you can configure another OpenAI-compatible server. The model must support the selected structured output. Check your server’s model settings if you need inference to stay on your computer.

Can I control response length and thinking?

Yes. The response-token limit defaults to 16,384 and helps bound generation cost and waiting time. Thinking defaults to Off for DeepSeek and Model default for other presets. Available controls depend on the provider and model. Save and retest after changing them.

What does ThunderClaw cost?

ThunderClaw is open source under the Apache 2.0 license. You supply the model connection. Hosted providers may charge for generation, including connection tests; a model running on your computer uses your own hardware.
