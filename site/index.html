Install ThunderClaw

From OpenClaw to your inbox
in four clear steps.

ThunderClaw has two matching parts: a plugin for your OpenClaw Gateway and a signed extension for Thunderbird. Install both, then pair them once.

  1. 01

    Get OpenClaw ready

    Use a supported OpenClaw version from 2026.7.2-beta.7 through the 2026.9.1 release line with a configured agent, then confirm that its Gateway is running.

    openclaw gateway status
    OpenClaw installation guide ↗
  2. 02

    Install the OpenClaw plugin

    Install the published package directly from ClawHub, enable it, and restart the Gateway so the new plugin is loaded.

    openclaw plugins install clawhub:@thunderclaw/openclaw-plugin
openclaw plugins enable thunderclaw
openclaw gateway restart
    View ThunderClaw on ClawHub ↗
  3. 03

    Add ThunderClaw to Thunderbird

    Open the official listing in Thunderbird 128 or newer, choose Add to Thunderbird, and approve the requested permissions.

    Get the Thunderbird extension ↗
  4. 04

    Connect and pair

    Open ThunderClaw’s settings in Thunderbird, enter the endpoint shown by your OpenClaw installation, and choose Pair this Thunderbird. Then run the guided approval command:

    openclaw thunderclaw

    Match the approval code, approve the request, then return to Thunderbird to Claim approved pairing and test the connection.

    Detailed pairing and troubleshooting guide ↗

Connecting to another machine? Use an HTTPS endpoint. Plain HTTP is accepted only for explicit 127.0.0.1 or [::1] loopback addresses.
